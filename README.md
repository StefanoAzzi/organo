# органо (Organo)

![Banner do Projeto](https://cursos.alura.com.br/course/react-desenvolvendo-javascript)

## 📖 Sobre o Projeto

O **Organo** é uma aplicação web desenvolvida durante o curso de React da [Alura](https://www.alura.com.br/). O objetivo é criar uma plataforma para organizar equipes e seus membros, permitindo a criação de "cards" de colaboradores e sua distribuição em times.

Este projeto foi fundamental para praticar conceitos essenciais do React, incluindo:

- **Componentização:** Criação de componentes reutilizáveis para a interface.
- **Props:** Comunicação e passagem de dados entre componentes.
- **Estado:** Gerenciamento de estado com o hook `useState`.
- **Eventos e Formulários:** Manipulação de inputs de usuário para adicionar novos colaboradores.
- **Renderização de Listas:** Exibição dinâmica dos membros de cada time.

O ambiente de desenvolvimento utilizado foi o [CodeSandbox](https://codesandbox.io/), uma plataforma online que facilita a criação e o compartilhamento de projetos web.

## 🚀 Funcionalidades

- **Formulário de Cadastro:** Permite adicionar um novo colaborador com nome, cargo, imagem e time.
- **Criação de Times:** Organiza os colaboradores em seções distintas, cada uma com um nome e cor de destaque.
- **Cards de Colaborador:** Exibe as informações de cada membro da equipe de forma visualmente agradável.
- **Design Responsivo:** A interface se adapta a diferentes tamanhos de tela.

## ⚙️ Como Executar

Como este projeto foi desenvolvido no CodeSandbox, a maneira mais fácil de executá-lo é acessando o link da demonstração. Caso queira rodá-lo localmente, você pode fazer o download do projeto (Zip) no CodeSandbox e seguir os passos:

1.  **Descompacte a pasta do projeto.**

2.  **Abra o terminal na pasta do projeto e instale as dependências:**

    ```bash
    npm install
    ```

3.  **Inicie o servidor de desenvolvimento:**

    ```bash
    npm start
    ```

4.  A aplicação estará disponível em `http://localhost:3000`.
